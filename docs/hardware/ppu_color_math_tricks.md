---

## 반투명 레이어

### 50% 반투명 배경

```asm
; BG1 (메인) + BG2 (서브) 50% 블렌딩
LDA #$01
STA $212E    ; TM = BG1
LDA #$02
STA $212F    ; TS = BG2
LDA #$82     ; Half + BG1
STA $2131
```

---

## 빛 효과

### 빛나는 오브젝트

```asm
; 스프라이트 주변 밝게
LDA #$20     ; Add + OBJ
STA $2131
; 고정 색상 = 흰색
LDA #$FF
STA $2132
```

## 그림자

### 어두운 그림자

```asm
; 스프라이트 아래 어둡게
LDA #$60     ; Subtract + OBJ
STA $2131
; 고정 색상 = 검정
LDA #$00
STA $2132
```

---

## 페이드 인/아웃

### 검정으로 페이드

```asm
; 검정색으로 서서히 어둡게
LDA FadeLevel  ; 0-31
ORA #$E0       ; R/G/B 비트
STA $2132
LDA #$3F       ; Subtract all
STA $2131
```

---

## 물/유리 효과

### 반투명 물 표면

```asm
; BG1 (물) 50% 반투명
LDA #$82     ; Half + BG1
STA $2131
; 모자이크로 왜곡 효과
LDA #$31     ; Size=3, BG1
STA $2106
```
